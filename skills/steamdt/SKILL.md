# SteamDT 饰品行情

通过已连接的 SteamDT 官方 MCP 查询数据，按用户语言回答。先识别饰品与查询口径，再调用完成请求所需的工具。

## 工具与连接

官方地址为 `https://mcp.steamdt.com/mcp`，使用 Streamable HTTP 和 Bearer API Key。工具可能带有客户端命名空间，按实际名称与输入 schema 调用。

首次使用或工具发生变化时检查可用工具，支持所需能力即可，不要求清单恰好固定为某个数量。参数、平台筛选、返回字段和已知限制见 [工具参考](references/tools.md)，仅在相关查询需要时读取。

如果工具没有加载，说明需要连接或重载 MCP；不要编造调用结果。只有用户要求配置时才修改客户端配置。凭证留在本机用户配置或凭证存储中，不索取聊天中的密钥，不写进 Skill、项目或输出。当前 Skill 不需要安装旧 Python MCP 包或获取全量饰品缓存。

## 确认饰品

- 用户给出完整英文 `marketHashName` 时可直接查询，保留大小写、符号和版本信息。
- 中文名、别名或不完整名称先调用 `search_items`，将选中结果的 `marketHashName` 原样用于后续查询。不要凭翻译猜英文名称。
- 按用户明确的武器、皮肤、磨损、StatTrak（暗金）或纪念品条件过滤候选；上下文能唯一确定时直接继续。若仍有影响价格的不同版本，简短列出候选并请用户选择，不取第一条代替选择。
- 用户明确要求比较多个版本时，可查询所需候选，不必强制缩成一个。搜索为空时可用更短的核心名称再查一次；仍无结果就说明未找到。
- 花纹、蓝量、贴纸、特殊款式和精确 float 可能影响单件价格；名称级行情不能当作该单件的精确估值。缺少所需能力时说明范围，不通过名称级工具捏造磨损数据。

## 选择查询

| 用户意图 | 工具与口径 |
| --- | --- |
| 现在多少钱、平台比价 | `get_item_prices`；区分在售底价、最高求购价（可能附条件）及对应数量 |
| 最近七天平均多少钱 | `get_item_average_price_7d`；保留返回的总体及各平台均价 |
| 饰品涨跌、价格走势 | `get_item_kline`；选择与问题相符的时 K、日 K 或周 K |
| 大盘现在怎么样 | `get_broad_index`；展示指数及返回的相对昨日变化 |
| 大盘走势 | `get_broad_kline`；解释趋势的实际时间范围 |

没有明确周期的普通趋势查询可用日 K，并注明口径；平台未指定时可用工具默认值。不要为一个简单均价问题附带查询所有行情工具。比较多个标的时保持平台、时间范围与版本口径一致，复用本次任务已获得且仍适用的数据。

## 解读数据

- 先检查 MCP `isError` 和业务错误，再解析 `structuredContent` 或文本 content 中的 JSON。成功连接不代表业务查询成功。
- 七日均价是汇总值，不是七个每日价格，更不是任意 `days` 的历史序列。总体 `avgPrice` 使用服务返回值；不擅自对平台均价求平均替代它。
- 价格统一按人民币元（CNY）展示：这是本项目由用户确认的数据口径，响应省略币种时也适用，无需反复提示币种缺失。若后续响应明确指定其他币种，则按实际币种标注，不混算不同币种；大盘指数和涨跌幅分别用指数点和百分比，不标“元”。
- 当前在售底价、最高求购价、均价和 K 线价格分别标注，不能把报价说成已成交价格。跨平台价差不等于扣除手续费、交易限制后的利润。
- 在售底价与最高求购价可能对应不同的订单条件，尤其是 float（具体磨损值）限制，也可能涉及花纹等要求。同一“略有磨损”等档位不保证可直接匹配成交。最高求购价高于在售底价是可能正常出现的情况，不能仅凭此判为数据异常、倒挂套利或可成交机会。
- 响应未给出求购条件时注明“具体求购条件需到平台核对”，不猜测具体 float 门槛。买入分析重点看用户目标版本的在售底价、同平台近期走势和具体单件磨损；最高求购价仅作辅助，不直接当作用户持仓可卖出的价格或价格支撑。
- 缺失、空值和无报价不当作零；零值含义不明确时标为待确认。缺少数据更新时间时可给出查询时间，但不能把它当成报价更新时间。
- 使用实际时间戳确定走势区间，必要时说明时区。区分完整序列、服务摘要覆盖范围和返回的最近若干点；只有点位范围足够时才据此计算指定区间涨跌。自算涨跌注明基准和公式 `(末值 - 初值) / 初值 × 100%`，初值为零时不计算。
- K 线字段含义或时间戳单位不明确时先核对 schema/官方文档，不猜列顺序，不承诺接口没有提供的成交量或成交记录。

## 输出与失败处理

先回答用户的核心问题。单个数值用短段落，平台或标的比较用表格；注明饰品版本、指标、平台、周期以及可用的时间和单位。价格表优先使用“在售底价（元）”“最高求购价（元，可能附条件）”等准确列名，不暗示两列对应相同条件。将数据来源标为 SteamDT 官方 MCP；有趋势分析时区分返回事实与推断，不把历史表现写成未来保证。

- “开放平台拒绝了凭证”：停止请求，让用户在本机检查 API Key 和鉴权格式，不要求贴出密钥。
- “该接口已达到配额上限”：停止相关查询，等待下一配额窗口；有服务返回的重置时间才报具体时间，不换 API 路径绕过配额。MCP 与直接 API 共用 API Key 配额。
- 超时或网络错误：说明失败。只有明确为临时故障且无认证/限额提示时最多重试一次；仍失败就停止，不自动循环。
- 部分查询失败时保留已成功结果并注明缺项，不编造补齐。空数据也不能据此断言饰品价格为零或市场没有交易。

## 使用例

- “USP 印花集现在多少钱？”：先搜名称；未明确磨损等版本且候选不唯一时让用户选择，再查当前价格。
- “查 AK-47 | Case Hardened (Field-Tested) 的七日均价”：直接调用均价工具，展示总体均价与用户需要的平台数据，不请求 K 线。
- “最近三十天涨了多少？”：确认标的后查询日 K，核对返回时间覆盖；覆盖不足时说明可算的实际区间，不以七日均价代替。
- “今天大盘如何？”：查询大盘指数，若用户还问走势再补充大盘 K 线。
- 在售底价 594 元、最高求购价 716 元：正常展示两项报价，说明求购可能限制具体磨损等条件，需到平台核对；不添加异常标记，不推断可套利，也不声称任意同档饰品都能以 716 元卖出。
